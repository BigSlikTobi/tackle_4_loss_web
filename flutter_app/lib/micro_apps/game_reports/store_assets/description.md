# Game Reports

AI-powered post-game recaps for every NFL matchup.

## Features

- **Instant Recaps**: Get detailed game summaries for any completed game
- **Multiple Styles**: Choose from Casual, Detailed, or Stats-focused reports
- **AI Enhancement**: Upgrade any report with cloud-powered AI analysis
- **Offline Ready**: Basic reports work 100% offline with local AI

## How It Works

1. Select any completed game from the schedule
2. Choose your preferred report style
3. Generate a local report instantly
4. Optionally enhance with AI for richer analysis (5 per day)

## Privacy

All basic reports are generated on-device using local AI. Cloud enhancement is optional and clearly labeled.
