# Player Wordle

**Guess the Mystery NFL Player!**

Put your NFL knowledge to the test in this addictive guessing game. Each round, you have 8 attempts to identify a mystery player using color-coded feedback clues.

## How to Play

1. **Search** for any NFL player using the search bar
2. **Submit** your guess and see how it compares
3. **Analyze** the color-coded feedback:
   - 🟢 **Green** = Exact match
   - 🟡 **Yellow** = Close (same side of ball, within 2 numbers)
   - ⬜ **Grey** = No match
4. **Deduce** the mystery player before your 8 guesses run out!

## Attributes Compared

- **Conference** (AFC/NFC)
- **Division** (North/South/East/West)
- **Team**
- **Position**
- **Jersey Number** (with ↑↓ arrows)
- **Age** (with ↑↓ arrows)
- **Height** (with ↑↓ arrows)

## Features

- 🏆 **Unlimited Play** - Play as many games as you want
- 📊 **Statistics** - Track your wins, streaks, and win percentage
- 💡 **Hint System** - Reveal the player's college if you're stuck
- 👤 **Progressive Reveal** - The mystery silhouette unveils as you guess
